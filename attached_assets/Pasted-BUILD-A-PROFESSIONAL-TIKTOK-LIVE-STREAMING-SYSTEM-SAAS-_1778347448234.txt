------------------------------------

3. PROXY SYSTEM (ANTI IP BLOCK)
------------------------------------
Create proxy server:

Routes:
GET /proxy/tiktok/:username
GET /proxy/streamdps/:username

Rules:
- Forward requests through server
- Add headers:
  - User-Agent: Mozilla
  - Referer: streamdps.com
- Prevent IP_BLOCKED errors
